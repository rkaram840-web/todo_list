# DayTask — To-Do List

A responsive task manager built with HTML, CSS, and vanilla JavaScript.

## Features
- Add tasks
- Mark tasks as completed
- Delete tasks
- Filter all, active, and completed tasks
- Progress bar and task counters
- Saves tasks in browser Local Storage
- Responsive layout for mobile and desktop

## Run
1. Extract `DayTask.zip`.
2. Open `index.html` in a browser.

No installation or build tools are required.

Note: Google Fonts are loaded online; the app itself works offline using system fallback fonts.
